# Memonowz 브랜드 자산

겹친 카드와 체크 표시를 품은 전구를 사용한다. 카드로 자료를 모으고, 답을 떠올리고, 확인하는 학습 흐름을 표현한다.

- 강조색: 딥 페트롤 `#1F5A6B`
- 카드: 아이보리 `#FAF6EC`
- 뒤쪽 카드: `#8BC5D3`
- 서체: IBM Plex Sans KR

## 파일

| 용도 | 파일 |
|---|---|
| 아이콘 원본 | [public/icon.svg](../public/icon.svg) |
| PWA 아이콘 | `public/icon-192.png`, `public/icon-512.png` |
| Maskable 아이콘 | `public/icon-192-maskable.png`, `public/icon-512-maskable.png` |
| iOS 홈 화면 | `public/apple-touch-icon.png` |
| 브라우저 탭 | `public/favicon-16.png`, `public/favicon-32.png` |
| README 배너 | [assets/brand-banner.svg](assets/brand-banner.svg), [assets/brand-banner.png](assets/brand-banner.png) |
| 공유용 이미지 | [assets/social-preview.png](assets/social-preview.png) (1280×640) |

PNG는 벡터 원본을 각 크기에 맞춰 렌더링한 자산이다. Maskable 버전은 배경을 끝까지 채우고 카드 표식을 중앙의 안전영역 안으로 줄였다. 작은 favicon도 같은 원본을 사용한다.

README에는 서체가 일관되게 보이도록 PNG 배너를 사용한다. 배너의 문구와 구성은 SVG 원본에 보관한다.

공유용 이미지는 GitHub **Settings → Social preview**에서 업로드할 수 있다. 파일을 저장소에 넣는 것만으로 저장소의 공유 미리보기가 바뀌지는 않는다. [GitHub 설정 안내](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/customizing-your-repositorys-social-media-preview)를 참고한다.
