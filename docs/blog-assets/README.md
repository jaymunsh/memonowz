## 서사에 쓸 기록

`.claude/session/devlog.md` 에 턴 단위 기록과 `**결정:**` 라인이 쌓여 있다. `.gitignore` 로 저장소에서는 빠져 있으니 글 쓸 때 로컬에서 꺼내 쓴다.

특히 남겨둔 것:
- **모델 id 실패** — `worker-start --model luna` 가 `stage: input_accepted` 를 돌려줬는데 실제로는 Codex API에서 거부됐다. 실제 id는 `gpt-5.6-luna`. CLI가 인자를 받은 것과 모델이 붙은 것은 별개였고, 워커 터미널을 읽어서야 알았다. "무엇을 성공 신호로 삼을 것인가"의 사례.
- **계획을 뒤집은 경위** — 처음엔 선행 단계를 코디네이터가 직접 구현하는 계획이었다. "그러면 멀티 오케스트레이션이 맞나"라는 지적에 뒤집었다.
- **병렬 폭을 8워커에서 4세션으로 줄인 판단** — 폭을 넓히면 워커 토큰은 선형으로, 코디네이터 추적 비용은 그보다 빨리 늘어난다.
