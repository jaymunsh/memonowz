# Memonowz 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 덱에 카드를 넣고, 객관식으로 반복해서 풀고, 틀린 것만 다시 푸는 로컬 전용 PWA 암기 앱을 만든다.

**Architecture:** 브라우저 안에서 완결된다. 서버도 계정도 없고 데이터는 IndexedDB(Dexie)에만 있다. `types`(계약) → `db`(저장소) → `ui`/`card`(공유 UI) 순으로 먼저 굳힌 뒤, 이 여섯을 읽기만 하는 세 개의 기능 모듈(`deck`/`study`/`import`)을 orca 워크트리에서 병렬로 구현한다. 기능 모듈은 서로를 참조하지 않는다.

**Tech Stack:** Vite 6 · React 19 · TypeScript 5 · react-router-dom 7 · Dexie 4 · zod 3 · nanoid 5 · vite-plugin-pwa 0.21 · @fontsource/ibm-plex-sans-kr · vitest 2 · fake-indexeddb 6 · pnpm

**Spec:** `docs/superpowers/specs/2026-08-29-memonowz-design.md`

## Global Constraints

- 패키지 매니저는 **pnpm**. 명령은 전부 `pnpm` 접두사로 쓴다.
- **새 의존성을 추가하지 않는다.** 위 Tech Stack이 전부다. 필요하다고 판단되면 직접 설치하지 말고 코디네이터에게 올린다(`orca orchestration ask`).
- **색·간격·서체를 CSS에 직접 쓰지 않는다.** 전부 `src/ui/tokens.css`의 CSS 변수를 통한다. `#fff`, `14px` 같은 리터럴 색·서체가 컴포넌트에 나타나면 잘못된 것이다.
- **UI 문구는 한국어.** 버튼은 일어날 일을 그대로 말한다(`저장`, `삭제`, `학습 시작`).
- 타입과 검증 스키마는 **`src/types/`에서만** 나온다. 다른 곳에서 카드 모양을 다시 정의하지 않는다(`z.infer`로 파생).
- 파일 하나가 200줄을 넘으면 책임이 둘 이상이라는 신호다. 쪼갠다.
- 커밋 메시지는 한국어 한 줄 요약 + 필요시 본문. `feat:`/`fix:`/`test:`/`chore:` 접두사를 쓴다.
- 테스트는 vitest. **화면 렌더링 테스트는 쓰지 않는다** — 로직(`study/engine`, `import` 파서, `db`)만 검증한다.
- 접근성 기본은 지킨다: 모든 인터랙티브 요소에 보이는 포커스 링(`:focus-visible`), 아이콘 단독 버튼에 `aria-label`, 모달에 `role="dialog"` + Esc 닫기.

- [ ] **Step 6: 아이콘 생성**

`public/icon-192.png`, `public/icon-512.png` 를 아이보리(`#FAF6EC`) 바탕에 딥 페트롤(`#1F5A6B`) 글자 `M` 으로 만든다. 다음을 실행한다:

```bash
python3 - <<'PY'
import struct, zlib
def png(path, size):
    bg = (0xFA, 0xF6, 0xEC); fg = (0x1F, 0x5A, 0x6B)
    # 가운데 정사각형 블록을 M 대신 단색 마크로 둔다 — 로고는 나중에 교체 가능
    rows = []
    m0, m1 = size // 4, size * 3 // 4
    for y in range(size):
        row = bytearray([0])
        for x in range(size):
            c = fg if (m0 <= x < m1 and m0 <= y < m1) else bg
            row += bytes(c)
        rows.append(bytes(row))
    raw = b''.join(rows)
    def chunk(t, d):
        c = t + d
        return struct.pack('>I', len(d)) + c + struct.pack('>I', zlib.crc32(c) & 0xffffffff)
    data = (b'\x89PNG\r\n\x1a\n'
            + chunk(b'IHDR', struct.pack('>IIBBBBB', size, size, 8, 2, 0, 0, 0))
            + chunk(b'IDAT', zlib.compress(raw))
            + chunk(b'IEND', b''))
    open(path, 'wb').write(data)
png('public/icon-192.png', 192)
png('public/icon-512.png', 512)
PY
```

```ts
import { z } from 'zod'

export const cardStatsSchema = z.object({
  right: z.number().int().nonnegative(),
  wrong: z.number().int().nonnegative(),
  lastSeenAt: z.number().nullable(),
})
export type CardStats = z.infer<typeof cardStatsSchema>

const shared = {
  tags: z.array(z.string()).default([]),
  explanation: z.string().optional(),
}

export const termInputSchema = z.object({
  type: z.literal('term'),
  front: z.string().min(1),
  back: z.string().min(1),
  /** 직접 넣은 오답 보기. 없으면 같은 덱 다른 카드의 back에서 뽑는다 */
  distractors: z.array(z.string()).optional(),
  ...shared,
})

export const mcqInputSchema = z.object({
  type: z.literal('mcq'),
  question: z.string().min(1),
  choices: z.array(z.string().min(1)).min(2),
  answer: z.number().int().nonnegative(),
  ...shared,
})

export const qaInputSchema = z.object({
  type: z.literal('qa'),
  question: z.string().min(1),
  answer: z.string().min(1),
  ...shared,
})

// discriminatedUnion의 멤버에는 .refine을 걸 수 없어(ZodEffects가 되어 거부된다)
// 교차 필드 검증은 union 바깥에서 한다.
export const cardInputSchema = z
  .discriminatedUnion('type', [termInputSchema, mcqInputSchema, qaInputSchema])
  .superRefine((card, ctx) => {
    if (card.type === 'mcq' && card.answer >= card.choices.length) {
      ctx.addIssue({
        code: z.ZodIssueCode.custom,
        path: ['answer'],
        message: 'answer가 choices 범위를 벗어남',
      })
    }
  })

export type CardInput = z.infer<typeof cardInputSchema>
export type CardType = CardInput['type']

export type Card = CardInput & {
  id: string
  deckId: string
  stats: CardStats
}

export const emptyStats = (): CardStats => ({ right: 0, wrong: 0, lastSeenAt: null })
```

```ts
import { nanoid } from 'nanoid'
import { db } from './db'
import { clearActiveSession, getActiveSession } from './session'
import type { Deck, DeckInput, DeckSummary } from '../types'

export const createDeck = async (input: DeckInput): Promise<Deck> => {
  const deck: Deck = { ...input, id: nanoid(), createdAt: Date.now() }
  await db.decks.add(deck)
  return deck
}

export const getDeck = (id: string) => db.decks.get(id)

export const updateDeck = async (id: string, patch: Partial<DeckInput>) => {
  await db.decks.update(id, patch)
}

export const deleteDeck = async (id: string) => {
  await db.transaction('rw', db.decks, db.cards, async () => {
    await db.cards.where('deckId').equals(id).delete()
    await db.decks.delete(id)
  })
  // 지운 덱의 세션이 남아 있으면 이어하기가 빈 덱을 가리킨다
  const session = await getActiveSession()
  if (session?.deckId === id) await clearActiveSession()
}

export const listDeckSummaries = async (): Promise<DeckSummary[]> => {
  const decks = await db.decks.orderBy('createdAt').reverse().toArray()
  const cards = await db.cards.toArray()
  return decks.map((deck) => {
    const own = cards.filter((c) => c.deckId === deck.id)
    const right = own.reduce((n, c) => n + c.stats.right, 0)
    const wrong = own.reduce((n, c) => n + c.stats.wrong, 0)
    const total = right + wrong
    return { ...deck, cardCount: own.length, accuracy: total === 0 ? null : right / total }
  })
}
```

```ts
  await db.cards.put({ ...input, id, deckId: existing.deckId, stats: existing.stats })

  await db.cards.update(cardId, {
    stats: {
      right: card.stats.right + (correct ? 1 : 0),
      wrong: card.stats.wrong + (correct ? 0 : 1),

  })
```

```ts
import { createCards, listCards } from './cards'

/** 저장소에만 있는 필드를 떨어뜨린다 — 백업 파일은 임포트 스키마와 같은 모양이어야 한다 */

export const exportDeck = async (deckId: string): Promise<Backup> => {
  const deck = await db.decks.get(deckId)
  if (!deck) throw new Error('덱을 찾을 수 없습니다')
  const cards = await listCards(deckId)
  return {
    deck: { name: deck.name, ...(deck.description ? { description: deck.description } : {}) },
    cards: cards.map(toInput),
  }
}

export const exportAll = async (): Promise<AllBackup> => {
  const decks = await db.decks.toArray()
  const all = await Promise.all(decks.map((d: Deck) => exportDeck(d.id)))
  return { decks: all }
}

export const importBackup = async (backup: Backup): Promise<Deck> => {
  const deck = await createDeck(backup.deck)
  if (backup.cards.length > 0) await createCards(deck.id, backup.cards)
  return deck
```

```tsx
export const Modal = ({ open, title, onClose, children, footer }: {
  open: boolean
  title: string
  onClose: () => void
  children: ReactNode
  footer?: ReactNode
}) => {
  useEffect(() => {
    if (!open) return
    const onKey = (e: KeyboardEvent) => { if (e.key === 'Escape') onClose() }
    document.addEventListener('keydown', onKey)
    return () => document.removeEventListener('keydown', onKey)
  }, [open, onClose])

  if (!open) return null
  return (
    <div className="modal__scrim" onClick={onClose}>
      <div
        className="modal"
        role="dialog"
        aria-modal="true"
        aria-label={title}
        onClick={(e) => e.stopPropagation()}
      >
        <header className="modal__bar">
          <h2>{title}</h2>
          <button type="button" className="modal__close" onClick={onClose} aria-label="닫기">✕</button>
        </header>
        <div className="modal__body">{children}</div>
        {footer && <footer className="modal__foot">{footer}</footer>}
      </div>
    </div>
  )
}
```

- [ ] **Step 1: `src/card/CardEditor.tsx` 작성**

```tsx
import { useEffect, useState } from 'react'
import { Button, Field, Modal, Tabs } from '../ui'
import { cardInputSchema, type Card, type CardInput, type CardType } from '../types'
import { createCard, deleteCard, getCard, updateCard } from '../db'
import './CardEditor.css'

const TYPES = [
  { value: 'term' as const, label: 'term' },
  { value: 'mcq' as const, label: 'mcq' },
  { value: 'qa' as const, label: 'qa' },
]

type Draft = {
  type: CardType
  front: string
  back: string
  question: string
  answerText: string
  choices: string[]
  answerIndex: number
  explanation: string
  tags: string
}

const emptyDraft = (): Draft => ({
  type: 'term', front: '', back: '', question: '', answerText: '',
  choices: ['', '', '', ''], answerIndex: 0, explanation: '', tags: '',
})

const toDraft = (card: Card): Draft => ({
  ...emptyDraft(),
  type: card.type,
  explanation: card.explanation ?? '',
  tags: card.tags.join(', '),
  ...(card.type === 'term' ? { front: card.front, back: card.back } : {}),
  ...(card.type === 'mcq'
    ? { question: card.question, choices: card.choices, answerIndex: card.answer }
    : {}),
  ...(card.type === 'qa' ? { question: card.question, answerText: card.answer } : {}),
})

const toInput = (d: Draft): CardInput | null => {
  const tags = d.tags.split(',').map((t) => t.trim()).filter(Boolean)
  const explanation = d.explanation.trim() || undefined
  const raw =
    d.type === 'term'
      ? { type: 'term', front: d.front.trim(), back: d.back.trim(), tags, explanation }
      : d.type === 'mcq'
        ? {
            type: 'mcq', question: d.question.trim(),
            choices: d.choices.map((c) => c.trim()).filter(Boolean),
            answer: d.answerIndex, tags, explanation,
          }
        : { type: 'qa', question: d.question.trim(), answer: d.answerText.trim(), tags, explanation }
  const parsed = cardInputSchema.safeParse(raw)
  return parsed.success ? parsed.data : null
}

export const CardEditor = ({ deckId, open, card, onClose, onSaved, onDeleted }: {
  deckId: string
  open: boolean
  card?: Card
  onClose: () => void
  onSaved: (card: Card) => void
  onDeleted?: (cardId: string) => void
}) => {
  const [draft, setDraft] = useState<Draft>(emptyDraft)
  const [error, setError] = useState<string | null>(null)

  useEffect(() => {
    if (open) {
      setDraft(card ? toDraft(card) : emptyDraft())
      setError(null)
    }
  }, [open, card])

  const set = <K extends keyof Draft>(key: K, value: Draft[K]) =>
    setDraft((d) => ({ ...d, [key]: value }))

  const save = async () => {
    const input = toInput(draft)
    if (!input) {
      setError('필수 항목이 비었거나 정답이 보기 범위를 벗어났습니다.')
      return
    }
    if (card) {
      await updateCard(card.id, input)
      const updated = await getCard(card.id)
      if (updated) onSaved(updated)
    } else {
      onSaved(await createCard(deckId, input))
    }
    onClose()
  }

  const remove = async () => {
    if (!card) return
    await deleteCard(card.id)
    onDeleted?.(card.id)
    onClose()
  }

  return (
    <Modal
      open={open}
      title={card ? '카드 편집' : '카드 추가'}
      onClose={onClose}
      footer={
        <>
          <Button variant="primary" onClick={save}>저장</Button>
          {card && <Button variant="danger" onClick={remove}>삭제</Button>}
        </>
      }
    >
      <Tabs
        label="카드 유형"
        options={TYPES}
        value={draft.type}
        onChange={(v) => set('type', v)}
      />

      {draft.type === 'term' && (
        <>
          <Field label="앞면" value={draft.front} onChange={(e) => set('front', e.target.value)} />
          <Field label="뒷면" as="textarea" value={draft.back} onChange={(e) => set('back', e.target.value)} />
        </>
      )}

      {draft.type === 'mcq' && (
        <>
          <Field label="문제" as="textarea" value={draft.question} onChange={(e) => set('question', e.target.value)} />
          <fieldset className="editor__choices">
            <legend>보기 · 정답을 고르세요</legend>
            {draft.choices.map((choice, i) => (
              <label key={i} className="editor__choice">
                <input
                  type="radio"
                  name="answer"
                  checked={draft.answerIndex === i}
                  onChange={() => set('answerIndex', i)}
                />
                <input
                  className="editor__choice-text"
                  value={choice}
                  aria-label={`보기 ${i + 1}`}
                  onChange={(e) => {
                    const next = [...draft.choices]
                    next[i] = e.target.value
                    set('choices', next)
                  }}
                />
              </label>
            ))}
          </fieldset>
        </>
      )}

      {draft.type === 'qa' && (
        <>
          <Field label="질문" as="textarea" value={draft.question} onChange={(e) => set('question', e.target.value)} />
          <Field label="모범답안" as="textarea" value={draft.answerText} onChange={(e) => set('answerText', e.target.value)} />
        </>
      )}

      <Field label="개념 설명 · 선택" as="textarea" value={draft.explanation} onChange={(e) => set('explanation', e.target.value)} />
      <Field label="태그 · 쉼표로 구분" value={draft.tags} onChange={(e) => set('tags', e.target.value)} />

      {error && <p className="editor__error">{error}</p>}
    </Modal>
  )
}
```

```ts
export type ThemePref = 'system' | 'light' | 'dark'

const KEY = 'memonowz.theme'

export const getThemePref = (): ThemePref => {
  const saved = localStorage.getItem(KEY)
  return saved === 'light' || saved === 'dark' ? saved : 'system'
}

export const applyTheme = (pref: ThemePref) => {
  const root = document.documentElement
  if (pref === 'system') root.removeAttribute('data-theme')
  else root.setAttribute('data-theme', pref)
}

export const setThemePref = (pref: ThemePref) => {
  if (pref === 'system') localStorage.removeItem(KEY)
  else localStorage.setItem(KEY, pref)
  applyTheme(pref)
}
```

```ts
import { cardInputSchema, type CardInput } from '../types'

export type ImportError = { index: number; message: string }

export const validateCards = (raw: unknown[]): { ok: CardInput[]; errors: ImportError[] } => {
  const ok: CardInput[] = []
  const errors: ImportError[] = []
  raw.forEach((item, i) => {
    const parsed = cardInputSchema.safeParse(item)
    if (parsed.success) {
      ok.push(parsed.data)
      return
    }
    const issue = parsed.error.issues[0]
    const where = issue.path.length > 0 ? `${issue.path.join('.')}가 ` : ''
    errors.push({ index: i + 1, message: `${i + 1}번째 항목: ${where}${issue.message}` })
  })
  return { ok, errors }
}
```

```json
  "deck": { "name": "정보처리기사 1과목", "description": "2024 기출" },
  "cards": [
    { "type": "term", "front": "cohesion", "back": "응집도 — 모듈 내부 요소들이 하나의 목적에 얼마나 모여 있는가",

```

   - `샘플 받기` 버튼 — 위 JSON을 `Blob` + `URL.createObjectURL` 로 `memonowz-sample.json` 으로 내려받는다.
   - `<input type="file" accept="application/json">` 로 파일을 받아 `JSON.parse` → `backupSchema` 로 겉을 검사 → `validateCards(parsed.cards)`.
   - `answer` 는 0부터 세고, `id`·`stats`·`deckId` 는 쓰지 않는다는 점을 설명에 명시한다.
4. **붙여넣기 탭**
   - `Field as="textarea"` 에 텍스트, 카드 구분자(`한 줄씩` / `빈 줄로`)와 앞뒤 구분자(`탭` / `쉼표` / `줄바꿈` / `직접 입력`) 선택.
   - 입력이 바뀔 때마다 `parsePaste` 를 돌려 `{n}장이 인식되었습니다` 와 앞의 3장 미리보기를 보여준다.
5. **결과 처리(두 탭 공통)**
   - 실패가 있으면 `bad` 톤 영역에 `검증 실패 {n}건` 과 각 메시지를 줄바꿈으로 나열한다.
   - 하단 고정: 실패가 있으면 `통과분 {n}장만 넣기`(primary)와 `전부 취소`(ghost). 실패가 없으면 `{n}장 넣기` 하나.
   - 넣기를 누르면 `createCards(deckId, ok)` 후 `navigate('/deck/' + deckId)`.
   - **JSON 파일에 담긴 `deck` 이름은 무시한다** — 이 화면은 이미 있는 덱에 카드를 붙이는 경로다. 전체 백업 가져오기(새 덱 생성)는 설정 화면이 담당한다. 이 점을 화면에 한 줄로 적는다.

### Task 11: IndexedDB 접근 불가 경고 (코디네이터, Task 6 직후)

**Interfaces:**
- Consumes: `src/db`, `src/ui`
- Produces: `<StorageGuard>` — 저장소를 못 쓰면 배너를 띄우고 자식을 그대로 렌더한다

- [ ] **Step 1: `src/app/StorageGuard.tsx` 작성**

```tsx
import { useEffect, useState, type ReactNode } from 'react'
import { db } from '../db'
import './StorageGuard.css'

export const StorageGuard = ({ children }: { children: ReactNode }) => {
  const [blocked, setBlocked] = useState(false)

  useEffect(() => {
    db.open().catch(() => setBlocked(true))
  }, [])

  return (
    <>
      {blocked && (
        <p className="storage-warn" role="alert">
          이 브라우저에서 저장소를 쓸 수 없습니다. 프라이빗 모드에서는 덱과 학습 기록이 저장되지 않습니다.
        </p>
      )}
      {children}
    </>
  )
}
```

`src/app/StorageGuard.css`:

```css

  background: var(--bad-soft); color: var(--bad);

}
```
